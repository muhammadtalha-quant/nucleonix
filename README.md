# Nucleonix — NixOS Configuration Based on Nucleus Architecture

> [!NOTE]
> The term **Nucleus Architecture** is not a widespread term. It refers to a
> custom architecture inspired from dendritic pattern without
> [**flake-parts**](https://github.com/hercules-ci/flake-parts) or any complex
> frameworks like [**denful/den**](https://github.com/denful/den) yet keeping
> the configuration scalable to many hosts[^1].
> [**Click**](/docs/ARCHITECTURE.md) to read more about the architecture.

> [^1]: As long as you can maintain it and commit to it.
