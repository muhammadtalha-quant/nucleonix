# Nucleonix — NixOS Configuration Based on Nucleus Architecture

> [!NOTE]
> The term **Nucleus Architecture** is not a widespread term. It refers to a
> custom architecture inspired from dendritic pattern without
> [**hercules-ci/flake-parts**](https://github.com/hercules-ci/flake-parts) or
> any complex frameworks like [**denful/den**](https://github.com/denful/den)
> and [**numtide/flake-utils**](https://github.com/numtide/flake-utils) yet
> keeping the configuration scalable to many hosts[^1].</br>
> [**Visit this template repository**](https://github.com/muhammadtalha-quant/nucleus-template)
> to read more about the architecture.
